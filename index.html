📖 ANTES DE OBTENER EL CÓDIGO O LINK SEGUIR ESTOS PASOS SEGÚN TU PANTALLA
1. Tutorial para TELEVISOR: «Estoy de viaje»
  1. En tu televisor elige Esta es mi cuenta.
  2. Selecciona Estoy de viaje.
  3. ⚠️ Si no te sale «Estoy de viaje», pasa al paso 2.
  4. Elige Enviar correo.
  5. Recién ahora baja a consultar tu enlace aquí abajo.
2. Tutorial para TELEVISOR: «Cambiar hogar»
  1. En tu televisor elige Esta es mi cuenta.
  2. Selecciona la opción Cambiar hogar.
  3. Vuelve a presionar Cambiar hogar.
  4. Elige Enviar correo.
  5. Baja al formulario para confirmar el enlace.
3. Tutorial para CELULAR, TABLET o PC: «Ver temporalmente»
  1. En la pantalla de tu dispositivo elige Ver temporalmente.
  2. Selecciona Enviar correo.
  3. Ingresa tu número aquí abajo para obtener el acceso.
